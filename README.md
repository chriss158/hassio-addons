# Tom's Home Assistant Apps

This repository contains my personal apps (formerly known as add-ons) for Home Assistant. Feel free to install and use the apps if you find them useful.

## Installation

Navigate in your Home Assistant frontend to **Settings** -> **Apps** -> **App Store** and add this URL as an additional repository:
```txt
https://github.com/thomasmauerer/hassio-addons
```

## Apps in this repository
 - **[Samba Backup](/samba-backup/README.md)**: Create snapshots and store them on a Samba share.
